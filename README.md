# memento-front

Живое дерево: ветки, которые вы задаёте, вырастают на экране, как у настоящего
дерева. Листья можно включать и выключать; ветки видны всегда.

## Запуск

```sh
npm start        # http://localhost:5173 (порт меняется через PORT=…)
npm test         # юнит-тесты модели и геометрии (node --test)
```

Зависимостей нет: чистый JavaScript (ES-модули) и Canvas 2D. Нужен Node 20+
только для локального сервера и тестов.

## Что умеет

- Клик по ветке выбирает её; в панели можно добавить к ней дочернюю ветку,
  переименовать или удалить (вместе с потомками). Ствол удалить нельзя.
- Новая ветка прорастает из родителя, а ствол и ветки под ней плавно
  утолщаются (модель «трубок» да Винчи: площадь сечения равна сумме сечений
  выше). Соседние ветки при этом остаются на своих местах.
- «Задать структуру текстом»: одна строка — одна ветка, вложенность — отступом,
  первая строка — ствол. «Вырастить» выращивает дерево заново по тексту.
- Переключатели: листья (осыпаются и отрастают волной), подписи веток, ветер.
- Дерево сохраняется в `localStorage` браузера.

## Два вида

Переключатель «Живое / Схема 2D» в начале панели. Оба вида показывают одно и
то же дерево, а правки из панели видны в обоих.

- **Живое**: дерево на Canvas с корой, ветром и процедурными веточками.
- **Схема 2D**: плоское SVG-дерево, основа будущего генеалогического.
  - Каждое поколение стоит на своём ярусе: ствол внизу, потомки выше.
  - Ветки сужаются к концам, на концах стоят таблички с именами.
  - Порядок детей сохраняется, поддеревья не перекрываются. Раскладка — Reingold–Tilford, усреднённая по укладке слева и справа.
  - Новая ветка прорастает из родителя, соседи плавно расступаются.
  - Масштаб меняется колесом или щипком, дерево перетаскивается, кнопка «Вписать» возвращает общий вид.
  - Таблички выбираются кликом или с клавиатуры (Tab, затем Enter).
  - Кроме веток модели, у дерева есть декоративные веточки с листьями, чтобы
    оно было похоже на настоящее. «Показать узлы» включает таблички: ветки
    модели становятся тёмными и чёткими, остальная крона полупрозрачной.
    Если выключить, все ветки одинаковые и видно просто дерево.

## Устройство

| Файл | Что делает |
|---|---|
| `src/model.js` | Данные: ветки, добавление, удаление, текстовый формат |
| `src/layout.js` | Геометрия: план (ветки, процедурные веточки, листья) и поза на кадр (рост, ветер, листья) |
| `src/render.js` | Отрисовка Canvas: небо, земля, кора с объёмом, листья, выделение, подписи |
| `src/flat/layout.js` | Схема 2D: раскладка по поколениям, контуры веток, ствола и корней, листья. Чистые функции без DOM |
| `src/flat/view.js` | Схема 2D: SVG, анимация роста, камера (масштаб и перетаскивание), выбор таблички |
| `src/app.js` | Панель, переключение видов, события, анимационный цикл, сохранение |
